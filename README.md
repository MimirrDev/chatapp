<h2>Overview</h2>
<p>chatapp is an open-source, real-time chat platform designed to facilitate instant messaging and user interaction within a scalable architecture. Built with Node.js and WebSocket technology, it supports multi-room conversations, guilds, and voice features, making it ideal for creating interactive communication systems.</p>
<p><strong>Why chatapp?</strong></p>
<p>This project empowers developers to quickly deploy and customize real-time chat applications. The core features include:</p>
<ul class="list-disc pl-4 my-0">
<li class="my-0">🟢 <strong>Real-Time Messaging:</strong> Enables instant, bidirectional communication between users.</li>
<li class="my-0">🔵 <strong>Multi-Room Support:</strong> Facilitates organized conversations within channels and guilds.</li>
<li class="my-0">🟠 <strong>WebSocket Integration:</strong> Ensures low-latency, reliable message delivery.</li>
<li class="my-0">🟣 <strong>Full Stack Architecture:</strong> Combines a Node.js backend with a responsive frontend setup.</li>
<li class="my-0">🟡 <strong>Cross-Origin Compatibility:</strong> Supports seamless integration across different domains.</li>
<li class="my-0">🟤 <strong>Extensible Foundation:</strong> Serves as a robust base for adding voice, media, or custom features.</li>
</ul>

<h2>Getting Started</h2>
<h3>Prerequisites</h3>
<p>This project requires the following dependencies:</p>
<ul class="list-disc pl-4 my-0">
<li class="my-0"><strong>Programming Language:</strong> JavaScript</li>
<li class="my-0"><strong>Package Manager:</strong> Npm</li>
</ul>
<h3>Installation</h3>
<p>Build chatapp from the source and install dependencies:</p>
<ol>
<li class="my-0">
<p><strong>Clone the repository:</strong></p>
<pre><code class="language-sh">❯ git clone https://github.com/MimirrDev/chatapp
</code></pre>
</li>
<li class="my-0">
<p><strong>Navigate to the project directory:</strong></p>
<pre><code class="language-sh">❯ cd chatapp
</code></pre>
</li>
<li class="my-0">
<p><strong>Install the dependencies:</strong></p>
</li>
</ol>
<p><strong>Using <a href="https://www.npmjs.com/">npm</a>:</strong></p>
<pre><code class="language-sh">❯ npm install
</code></pre>
